Velocity Design System

typedesign-spec
version2.2.0
moodcold · austere · neutral
#obsidian#scss

Velocity is a sleek and futuristic theme for Obsidian — born out of a relentless, one-year-long pursuit of design perfection. This note documents the token architecture that makes a full identity change possible in under thirty lines.

The UI recedes; the content advances. Every surface is cool gray, distinguished by elevation rather than color.

Design Constitution

Velocity is a cold, austere interface — near-neutral in color, precise in weight, and uninterested in ornamentation. The only warmth permitted belongs to the user's content.

Constraint list
No rainbow headings, no decorative gradients, no loud accent colors, no typography contrast used for decoration.

Parametric Base Scale

Never hard-code lightness into color tokens. Separate parameters from formulas — a paint job overrides only --bhue, --bsat-*, --bl-* and semantic colors.

--bhue:       281;       // single hue anchor
--bsat-str:   0.00375;  // strong chroma: most stops
--bl-00:      23.50%;   // darkest (dark mode)

--color-base-00: oklch(var(--bl-00) var(--bsat-med) var(--bhue));

Glass Morphism

The defining visual signature — multi-stop inset shadows create the beveled edge highlight on every elevated surface.

Elevation hierarchy
Higher elevation = stronger glass + stronger shadow. A modal sits above a card; its shadow must read heavier.

Roadmap

  • Eight-layer SCSS architecture
  • OKLCh parametric token pipeline
  • Glass-morphism elevation system
  • Full mobile device support
  • Alternative Checkboxes reference set
