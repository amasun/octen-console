Ranked web results, highlights, and summaries. Ready for generation.

<62ms latency · Scales to 1M+ QPS

Video SearchEarly Access

Video retrieval across the open web. Ready for media discovery and research.

Extract

Clean markdown, intent-focused highlights, and page classification. Ready for ingestion.

Clean markdown extraction · success-only pricing
Works best for AI agents, RAG pipelines, and content monitoring.
Model

One API to call any LLM, with unified billing. Ready for production.

OpenAI-compatible · Switch providers without rewriting code.
Works best for multi-model apps, fallback chains, and cost routing.
Embedding

Vector embeddings for retrieval, similarity, and ranking. Ready for production.

client = Octen(api_key="YOUR_API_KEY")

response = client.extract(
    urls=[
        "https://docs.octen.ai/api-reference/search",
        "https://en.wikipedia.org/wiki/Artificial_intelligence",
    ],
    format="markdown",
    render="auto",
    max_age_seconds=86400,
    timeout=30,
)

for result in response.data.results:
    if result.status == "success":
        print(result.title)
        print(result.content[:500])
